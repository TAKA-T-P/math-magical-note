## 1. 技術構成と選定理由

| 項目 | 採用 | 比較した候補と理由 |
|---|---|---|
| 言語・UI | HTML / CSS / 素の JavaScript（ESモジュール） | React 等も検討したが、画面数が少なく状態も単純なため不要。依存を減らし、長期保守と教材担当者の参加を容易にする |
| 開発・ビルド | Vite | 設定ほぼ不要、教材データを単元ごとに自動で分割読み込みできる（`import.meta.glob`） |
| 数式 | KaTeX | MathJax より高速・軽量で、段階表示のたびに再描画しても遅れない。`\htmlClass` で数式の一部にキーを付けられ、部分強調に使える |
| 手書き | Canvas（Pointer Events） | マウス・ペン・タッチを同じ処理で扱える |
| 図形・グラフ | （未実装）SVG、必要に応じ JSXGraph | 4-3 の拡張時に `lab` 種別＋専用ブロックとして追加する |
| データ | JSON（単元＝節ごとに1ファイル） | |
| 公開 | 静的ファイル（GitHub Pages 等）。ハッシュ方式のURLで再読み込みしても壊れない | |
| オフライン | 簡易サービスワーカー（一度開いたリソースをキャッシュ） | |

## 4. 教材データ形式

### 4-1. カタログ（`src/data/catalog.json`）

```jsonc
{
  "editions": ["2026"],           // 対応している教材年度
  "grades": [{
    "id": "g2", "label": "中2", "enabled": true,
    "chapters": [{
      "id": "c2", "number": "第2章", "title": "連立方程式", "pages": { "2026": 24 },
      "sections": [
        { "id": "s1", "number": "第1節", "title": "加減法による解き方",
          "pages": { "2026": 24 }, "data": "g2/c2/s1" }   // data があれば教材あり
      ]
    }]
  }]
}
```

ページ番号は `pages: { 年度: ページ }` で持つため、年度ごとのページ変更はここだけ直せばよい。

### 4-2. コンテンツ（`src/data/g2/c2/s1.json` の `contents[]`）

| 項目 | 内容 |
|---|---|
| `id` | 一意のコンテンツID。**ページ番号・問題番号を含めない**（例 `g2.simul.elim.q-add-1`）。一度付けたら変えない |
| `rev` | 内容の版。年度で内容が変わったら、同じ `id` で `rev` を上げた別オブジェクトを追加し、`editions` で使い分ける |
| `editions` | 年度ごとの掲載情報 `{ "2026": { page, number, tags, ref } }` |
| `type` | `title`（章タイトル）/ `point`（ポイント解説）/ `exercise`（例題・演習）/ `similar`（類題）/ `advanced`（発展）/ `lab`（図形・グラフ実験） |
| `title` | 内容を表す短い名前 |
| `statement` | 問題（ステップ0）で表示するブロックの配列 |
| `steps` | 解説ステップの配列（下記） |
| `hints` | ヒント文の配列（最終解答は書かない） |
| `answer` | 正答（`tex` と、数値なら `values`） |
| `check` | 検算用。`equations`（もとの式）・`solution`（解）・`derived`（途中式）は解で成り立つかを確認。`identities`（式変形。例 `2*(2*x-3*y)=4*x-6*y`）は x, y にいろいろな値を入れて成り立つかを確認。`nonSolutions`（解でない組）はいずれかの式が崩れることを確認。さらに、画面に表示される `math` / `calc` / `answer` の各行が解で成り立つかを自動で検算する（対象外にするブロックは `verify: false`） |
| `teacher` | 講師向け情報：`aim` 指導のねらい / `questions` 発問例 / `pitfalls` つまずき / `commonErrors` よくある誤答 / `notes` 補足 / `procedure` 推奨手順。各項目は文字列か `{ text, source }`。`source: "material"` は本編・指導書に記載された内容（「教材」と表示）、`"draft"` は教材にない提案（「提案」と表示）。`source` を省略した項目は `status`（`draft` なら提案扱い）に従う。ステップの `teacherNote` も同じ形式 |

### 4-3. ブロック（表示テンプレート）

| `type` | 用途 | 主な項目 |
|---|---|---|
| `text` | 文章 | `text` |
| `math` | 数式（LaTeX） | `tex` |
| `callout` | 赤枠の注意・判断 | `text`, `tone` |
| `answer` | 答えの枠 | `tex` |
| `pointbox` | 教材の「ポイント」囲み | `title`, `items[]`（`text`, `note`, `strong`, `contIndent`） |
| `title-card` | 章タイトルと節一覧 | （カタログから自動生成） |
| `calc` | 筆算・式の整数倍・判定表 | `rows[]`（`label`, `op`, `cells[]`, `key`, `rule`, `note`, `head`）, `align` |
| `table` | 文章題の情報整理の表（13章） | `head[]`, `rows[]`（`key`, `cells[]`） |
| `illust` | 品物などのイメージイラスト（13章） | `items[]`（`asset`, `name`, `count`, `times`, `color`, `key`, `lines[]` / `sep`）, `height`, `maxRepeat` |
| `place` | 位取り表・数字カード（14章。状態を持つ） | `labels[]`, `cards[]`（`id`, `label`, `color`, `key`）, `states[]`（`id`, `order[]`, `values`, `tex`）, `state` |
| `bars` | ブロック図（14章。状態を持つ） | `total`, `parts[]`（`text`, `w`, `color`, `key`, `value`）, `groups[]`（`from`, `to`, `text`, `key`）, `states[]`, `state` |
| `route` | 線分図・移動の再生（15章。状態を持つ） | `points[]`, `segments[]`（`w`, `top`, `bottom`, `key`）, `total`, `side`, `icon`, `note`, `width`, `states[]`（`motion`） |
| `ratio` | 割合の帯グラフ（16章。状態を持つ） | `rows[]`（`id`, `label`, `color`）, `max`, `width`, `note`, `states[]`（`rows`：`pct`, `rate`, `base`, `delta`, `result`, `before`, `after`） |
| `beakers` | 食塩水のビーカー図（16章。状態を持つ） | `items[]`（`id`, `name`, `color`, `tint`）, `capacity`, `unknownLevel`, `height`, `between`, `note`, `states[]`（`items`：`amount`, `pct`, `salt`, `conc`, `water`, `saltText`, `ghost`／`mix`） |
| `circle` | 円周移動図（15章。状態を持つ） | `length`, `size`, `center`, `lengthLabel`, `runners[]`, `states[]`（`mode`, `view`, `frac`, `labels`, `speeds`, `until` …） |

`answer` は数式（`tex`）の代わりに文字（`text`、例「ウ」）も使える。`pointbox` の `items[]` には `key` を付けて項目ごと段階表示できる。

共通項目：`id`（必須）、`area`（`top` / `left` / `right` / `full`（左右2列にまたがる） / `bottom`）、`size`（`s` / `m` / `l`）、
`inline`（横に並べる）、`width`（横に並べるときの幅 px。問題文の横にイラストを置くときなど）、`hide`（最初は隠しておくキー）。

文章中の書式：`$...$` 数式、`**語句**` 赤太字、`__語句__` 下線、`{{key|語句}}` キー付き語句（赤太字・穴埋めにできる）、
`[[key|語句]]` キーだけを付けた語句（見た目は通常の文字。強調の対象にする）。
`{{ }}`・`[[ ]]` の中に数式（`$…$`）を入れてもよい（例：`[[dec2|両辺を $10$ 倍して]]`）。開き・閉じがそろっているかは validator が確認する。

#### calc ブロック（筆算・表）

```jsonc
{ "id": "calc", "type": "calc", "area": "left", "size": "l", "hide": ["r3"],
  "rows": [
    { "label": "①×2", "cells": ["4x", "\\hl{cy1}{{}-6y}", "=", "10"] },
    { "label": "②×3", "op": "[[op|+)]]", "cells": ["15x", "{}+6y", "=", "66"], "rule": true },
    { "key": "r3", "cells": ["19x", "", "=", "76"] }
  ] }
```

- 列ごとに項・等号・右辺が縦にそろう（`align` 省略時は「=」の列を中央、他は右寄せ）。
- `label`（①×2 など）は横線の外に出る。`rule: true` の行の下に、ラベル列を除いた横線を引く。
- `key` を付けた行は、行ごと段階表示・強調できる。セル内の `\hl` で項ごとの強調もできる。
- `note: true` の行は小さいオレンジ文字（整数倍の「↓×2」など）。`head: true` は見出し行（検算対象外）。
- セル先頭の符号付きの項は `{}-6y` と書く（符号の前後に通常の空白が入る）。
- 判定の ○ / × は `\ok` / `\ng`。

### 4-4. キーと段階表示

数式・文章の一部に **キー** を付け、ステップからそのキーを強調・表示する。

```latex
\hl{y1}{+3y}            % 「+3y」にキー y1（符号の前後の空白は自動）
{}+3y                   % 筆算（calc）のセル先頭の符号付きの項は {} を前に置く
```

ステップの項目：

| 項目 | 内容 |
|---|---|
| `id`, `title` | ステップID と見出し（操作内容。操作バーに表示） |
| `add` / `remove` | 追加・削除するブロック（「不要な部分の消去」） |
| `reveal` | `hide` していたキーを表示する（途中式を1行ずつ出す。レイアウトがずれない） |
| `emphasis` | `{ key, style, color, persist }`（`key` の代わりに `keys: [...]` で複数のキーに同じ強調をまとめて指定できる）。style は `color`（色変更）/ `box`（囲み）/ `marker`（ハイライト）/ `strike`（消去線）/ `dim`（薄く）。`persist: true` で以降のステップでも残す |
| `arrows` | `{ from, to, label, color }` キーからキーへの矢印（代入など） |
| `set` | `{ ブロックID: 状態ID }` 状態を持つブロック（`place` / `bars`）の表示を切りかえる（14章） |
| `anim` | 追加ブロックの登場方法：`fade` / `slide-up` / `slide-left` / `none` |
| `comment` | 生徒向けの補足コメント（画面下部） |
| `teacherNote` | 講師用メモにだけ表示する指導ポイント |

アニメーションは **登録済みの正しい式を順に見せるだけ** で、式を変形する演出は行わない（誤った式変形に見えないため）。

| モード | 内容 | → キー |

| 問題 | statement のみ | 解説のステップ1へ |

## 6. 問題を追加する手順

1. 教材PDFで問題文・数式・解答を確認する（年度版を正本とする）。
2. 該当する節の JSON（なければ新規作成し、`catalog.json` の節に `"data"` を追加）に `contents` を追加する。
3. `check` に元の式・解・途中式・式変形（`identities`）を登録する。表示される式は自動で検算される。
4. `npm run validate` で検証（数式の構文、キーの参照、検算）。ビルド時にも自動で実行され、エラーがあるとビルドが止まる。
5. `npm run dev` で授業画面を開き、全ステップを目で確認する（はみ出しはオレンジ枠で分かる）。
6. 講師向け情報は、本編・指導書に記載された内容だけ `source: "material"` を付け、それ以外は提案（draft）として登録する。

特殊な演出（グラフ・図形など）が必要な場合だけ、`renderer.js` の `BLOCK_BUILDERS` にブロック種別を追加する。

## 7. 今後の拡張に向けた設計上の配慮

- **講師用・生徒用ウィンドウ分離**：state.js の状態を BroadcastChannel で同期し、生徒用ウィンドウでは講師パネルを生成しない。
- **家庭学習モード**：同じ教材データと state.js を使い、`answer.values` で正誤判定、履歴は別ストレージ。
- **グラフ・図形**：`lab` 種別と `graph` / `figure` ブロック（SVG または JSXGraph）を追加。キーと emphasis の仕組みはそのまま使える。

| 変更 | 理由 | 既存機能への影響 |
|---|---|---|

| `[[key|語句]]` 書式、`pointbox` 項目の `key`、`answer` の `text` | ポイント解説の段階表示（「異符号」「同符号」の色分け、※の行を後から表示）と、記号で答える問題のため | なし |

| validator：表示式の自動検算・恒等式・非解の確認 | 整数倍・符号処理・代入の誤りをデータ登録時に検出するため | なし（検証が厳しくなるだけ） |

### 解説の表示方針（第1節で統一したもの）

- 「着目（強調）→ 判断（赤枠／青枠のメモ）→ 計算（筆算）→ 確認（代入・答え）」の順に進める。
- 「たす」は赤、「ひく」は青で統一（ポイント「加減法」と各問題の判断メモ・筆算の記号）。
- 整数倍は、問題文の横に「元の式 → ↓×n → 整数倍した式」を並べ、元の式との対応を残したまま筆算に進む。
- 消去される項は消去線（persist）で残し、以降のステップでも消えたことが分かるようにする。
- 代入は矢印（`arrows`）で「求めた値 → 代入先」を示す。

- ミニコンテンツはすべて独自コンテンツなので `status: "draft"` とし、カードと講師用メモに「要確認」を表示する。講師用メモの項目は「提案」と表示される。

## 10. 第2節（代入法）

### 10-1. データ

- 教材：`src/data/g2/c2/s2.json`（ポイント「代入法」・問2.1(1)(2)・↗問2.2）。`catalog.json` の第2節に `"data": "g2/c2/s2"` を追加。
- ミニコンテンツ：`src/data/mini/g2/c2/s2/`（3択ウォームアップ「加減法を思い出そう！」、ミスを見破れ！「代入法の落とし穴！」）。
- 途中式は指導書の解答例に合わせた（問2.1(1) は $x+(x+1)=3 \to 2x=2$、↗問2.2 は「①より $x=-3y-8$ …①'」→「①' に代入すると $x=9-8=1$」）。

### 10-2. 「置き換え」の見せ方（既存の emphasis・arrows・add・reveal の組み合わせ）

| 段階 | 表示 | データ |
|---|---|---|
| ① 代入する式 | ①の右辺（例 $x+1$）を **緑の囲み** | `emphasis: { key: "src", style: "box", color: "green" }` |
| ② 置き換える文字 | ②の文字（例 $y$）を **オレンジの囲み** ＋ 緑の矢印（式 → 文字） | `emphasis`（tgt, orange）＋ `arrows: [{ from: "src", to: "tgt" }]` |
| ③ 代入後の式 | 代入後の式のかっこ部分 $(x+1)$ を **緑の囲み** ＋ オレンジの矢印（文字 → 置き換わった式） | `add`（calc）＋ `arrows: [{ from: "tgt", to: "sub" }]` |

- 色の約束：**緑＝代入する式**、**オレンジ＝置き換えられる文字**。第3節以降でも同じ色を使う。
- かっこをはずす計算は、右の列に「$-2\times3y=-6y$」「$-2\times(-8)=+16$」のような補助の式（calc）を一時的に表示し、かける数（赤）と結果（囲み）を対応させる。補助の式は次の段階で `remove` する。
- 分配法則の前に「考えよう」のステップ（強調だけで新しい式を出さない）を置き、生徒が次の式を考える時間を確保する。

### 10-3. 追加・改善した共通機能

| 機能 | 内容 | 再利用 |
|---|---|---|
| 矢印の向き | これまでは「右へ向かう」形のみ。**真下・真上** の要素へ向かう矢印を縦向きに描くようにした（短い矢印は矢じりも小さく） | 式の中の文字 → 下の行、問題文 → 計算欄など、どの節でも使える |
| 節をまたぐ前後移動 | 授業画面のヘッダー ‹ › で、節の最初・最後は同じ章の前後の節（教材のある節）へ移動 | 新しい節を追加すると自動でつながる |
| 問題をまたぐ「次へ」「前へ」 | 最後のページ（次のステップがない）では「次へ」が「次の問題へ」、最初のページでは「前へ」が「前の問題へ」になり、ボタン・→ ← キーで前後の項目へ移る（行き先はヘッダーの ‹ › と同じ）。「前の問題へ」では移り先を最後のページ（全ステップ表示）で開く（`session.js` の `enterAtEnd`）。章の最初・最後では従来どおり押せない | 追加した節にも自動で適用 |
| ポイントの配置 | ポイント枠を上端に固定（補足コメントが出ても枠が動かず、手書きとずれない） | すべてのポイント |
| 表示式の検算 | 左辺が空の行（「$=\ \cdots$」と前の行から続く等式）も、前の行の左辺を引き継いで検算 | calc の複数行の等式 |
| ミスを見破れ！の検証 | 連立方程式でなく「式の計算そのもの」が題材のとき（`check.identity: true`）、正しい式は恒等的に成り立ち、誤答の式は成り立たない値があることを確認 | 計算ミス・符号ミス系の問題 |

### 10-4. 第3節以降への展開

- 「代入法」「加減法」のどちらの問題も、`src`（代入する式）・`tgt`（置き換える文字）・`sub`（代入後のかっこ）・`m`（かける数）・`d1`/`d2`（分配後の項）などのキー名をそろえておくと、データを複製して作りやすい。
- かっこ・分数・小数を含む連立方程式（第3節）でも、`calc` の補助式と `identities`（式変形の恒等式）で「両辺に何倍したか」を検証できる。

## 11. 第3節（小数・分数・かっこ・連等式）

### 11-1. 共通の流れ

どの問題も **「① 基本の形（$\bigcirc x+\triangle y=\square$）に整理する → ② これまでの加減法・代入法で解く」** の2段階にそろえた。

- 整理した式は **緑** で表示し、①'・②' の番号を付ける。
- 整理が終わったら、変形の途中式を `remove` で消し、右の列に ①'・②' をまとめて表示したうえで、左の列で加減法を行う（「今どの式を使っているか」がわかるように）。
- ステップの補足コメントに「ここからは加減法」と明示し、基本の形にすれば同じ解き方になることを伝える。

### 11-2. 表現と使った機能

| 表現 | 対象 | 方法（既存機能） |
|---|---|---|
| 式全体の10倍・100倍 | 問3.1 | `calc` の3行（元の式／`note` 行の「↓×10」をすべての項と右辺の下に／整数倍した式）。右辺は赤の囲みで強調 |
| 分母の最小公倍数 | 問3.2 | `calc` の文章セルで「8 の倍数：8，16，24，32，**40**」「10 の倍数：…，**40**」を並べ、40 を赤で囲む |
| 分母をはらう | 問3.2・3.4 | 整数倍の `calc`（↓×40 など）と、補助式「$12\times\frac{x-2}{3}=4(x-2)$」 |
| かっこの中の各項にかける | 問3.3 | かける数を赤、かっこの中の項を青で囲み、補助式「$-2\times x=-2x$」「$-2\times3y=-6y$」を表示 |
| 分子の多項式をひとまとまりに | 問3.4 | 分数の分子は緑のマーカー、分母をはらった後のかっこ $(x-2)$ は緑の囲み（同じ色で対応させる） |
| A=B=C から2式を取り出す | 問3.5 | $A$・$B$・$C$ を緑・青・オレンジで色分けし、`\underbrace{}_{A}` で名前を付けてから、取り出した2式を同じ色で表示 |

### 11-3. 追加・改善した共通機能

| 機能 | 内容 |
|---|---|
| 大きな分数（`\dfrac`）の検算 | validator が `\dfrac`・`\tfrac` をふくむ表示式も検算できるようにした |
| 文章中の連立方程式の余白 | 文章ブロックに連立方程式（cases）をふくむとき、大きな分数が行からはみ出さないよう上下に余白を取る（`:has(.mtable)`） |
| 囲み枠の線 | 線を 3.5px、式との間隔を 3px にして、隣の係数や分数の横線に重なりにくくした（全節共通） |

分数をふくむ連立方程式を文章中に書くときは、行が重ならないよう `\[0.6em]` で行間を広げる。

### 11-4. 新しい節を登録する手順（まとめ）

1. 教材PDF（本編・指導書）で問題文・途中式・答えを確認する（指導書の解答例の途中式を優先）。
2. `src/data/g2/<章>/<節>.json` を作り、`catalog.json` の節に `"data"` を追加する。
3. 各問題に `check`（`equations`・`solution`・`derived`・`identities`）を書く。整数倍・分配法則などの式変形は `identities` に入れる。
4. ミニコンテンツは `src/data/mini/g2/<章>/<節>/` に置く（すべて `status: "draft"`）。
5. `npm run validate` → `npm run dev` で全ステップと全解答を確認する（はみ出しはオレンジの破線枠で分かる）。

## 12. 第4節（解と係数）

### 12-1. 「何がわかっていて、何を求めるのか」の表示

| 役割 | 色 | 例（問4.1） |
|---|---|---|
| わかっている値（解） | 緑のマーカー | $x=2$，$y=-1$ |
| 値を代入される文字 | オレンジの囲み | 式の中の $x$，$y$ |
| 求めたい文字（定数） | 赤の囲み → 代入後の式は赤字 | $a$，$b$ |

- 最初のステップで右の列に「わかっている：$x=2,\ y=-1$（解）／求めたい：$a$，$b$（定数）」を `calc` の表で示し、$x$，$y$ を求めようとしないよう確認する。
- 代入後は「$x$，$y$ を代入すると → $a$，$b$ の連立方程式になる」と示し、ここからは加減法で解く。

### 12-2. 2組の連立方程式（↗問4.2）

- 問題文の2組の連立方程式は、本編どおり文章の中に左右に並べ、4本の式それぞれにキーを付ける。
- $a$，$b$ をふくまない2式は緑で囲み、残りの2式は `dim`（薄く）にする。取り出した2式で $x$，$y$ を求める。
- 「もとの問題に戻る」ステップで強調を入れかえ（$a$，$b$ をふくむ2式を赤で囲み、もう一方を薄く）、求めた $x$，$y$ を左上に残したまま代入する。
- 本編の問題文の下にあるヒントは、生徒に考えさせてから表示するため、2つ目のステップで右の列に出す。
- 途中式が増えすぎないよう、最後の文字を求める段階では加減法の筆算を片付け、「④に $a=4$ を代入」と答えだけを表示する。

### 15-2. 表示と再生の方針

- **答えが出るまでは模式図**：線分図の区間は同じ長さ、円周図の出会う位置は実際の比ではない位置（`frac`）で表示し、「模式図」と明記する。数値（10km・14km、分速220m など）や実際の比は表示しない。
- **答えのあとに実際の数値で再生**：答えのステップで、図を実際の道のりの比の状態（`set`）に切りかえ、「▶ 再生」ボタンを出す。再生は **講師がボタンを押したときだけ** 動く（生徒が考える時間を奪わない）。
- **速さと時間の比を保つ**：再生では「問題の時間 1単位 ＝ 何秒」（`secondsPerUnit`）を1つ決め、その中で全員の位置を「速さ×経過時間」で計算する。線分図は区間の長さを道のりに比例させるので、見た目の速さの比も正しい。画面には経過時間（問題の単位）と時間の縮め方（「1時間を1.5秒で再生」）を表示する。
- 停止・続きから・最初から ができる。ステップを変えて状態が変わると再生は止まり、最初の場面に戻る。別の問題・画面へ移ると再生ループも止まる。手書きモード中はペンの層が上にあるため、ボタンは押せない（手書きと干渉しない）。

### 16-2. 割合の帯グラフ（`ratio`）

```jsonc
{ "id": "bars", "type": "ratio", "area": "right", "width": 700, "max": 112,
```

### 16-3. 食塩水のビーカー図（`beakers`）

```jsonc

  "note": "※ 液の色は模式的なもの（実際の食塩水に色はない）。濃さは数値で確かめる",

  "states": [
    { "id": "s0", "items": { "A": { "conc": { "text": "濃度 5％" }, "water": { "text": "？g" } }, …, "M": { "ghost": true } } },

```

- ビーカーの下に **濃度・食塩水の量・食塩の量** を別々の行で表示し，段階的に書きこむ（問題文・表と同じキーで強調）。
