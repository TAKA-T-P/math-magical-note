# 動く魔法のノート

KECゼミナール オリジナル教材「魔法のノート」を使った、数学科講師向けの授業支援Webアプリ（電子黒板・プロジェクター向け）。

現在の収録範囲（中2数学 第2章 連立方程式）：

- 第1節 加減法による解き方（p.24〜25）：章タイトル・ポイント2件・問1.1・問1.2(1)(2)・問1.3(1)(2)
- 第2節 代入法による解き方（p.26）：ポイント「代入法」・問2.1(1)(2)・↗問2.2
- 第3節 いろいろな連立方程式の解き方（p.27〜29）：ポイント「いろいろな連立方程式」・問3.1（小数）・問3.2（分数）・問3.3（かっこ）・問3.4（分子が多項式）・問3.5(1)(2)（A=B=C 型）
- 第4節 連立方程式の解と係数（p.30）：問4.1（解から係数を求める）・↗問4.2（2組の連立方程式の解が一致する）
- 第5節 連立方程式の利用（p.31〜32）：ポイント「方程式を用いた文章題の解法」・問5.1（大根と人参）・問5.1 補足（1元1次方程式との比較）・問5.2（鉛筆とボールペン）
- 第6節 整数に関する問題（p.33）：問6.1（大小2つの整数・商とあまり）・問6.2（2けたの整数と位の入れかえ）
- 第7節 速さに関する問題（p.34〜35）：問7.1（道のりを x，y とおく）・問7.2（時間を x，y とおく）・↗問7.3（池の周りを走る2人）
- 第8節 割合に関する問題（p.36〜37）：ポイント「割合に関する問題」・問8.1（生徒数の増減）・問8.2（食塩水の混合）

授業ミニコンテンツ（すべて要確認の下書き）：

- 第1節：3択ウォームアップ・ミスを見破れ！・数学〇×クイズ・数学ミニコラム・導入トーク 各1本
- 第2節：3択ウォームアップ「加減法を思い出そう！」・ミスを見破れ！「代入法の落とし穴！」
- 第3節：3択ウォームアップ「連立方程式の基本を復習！」・ミスを見破れ！「分母・かっこの計算ミスを発見！」・数学〇×クイズ「いろいろな連立方程式」
- 第4節：3択ウォームアップ「連立方程式、解を代入できる？」・ミスを見破れ！「解と係数の落とし穴！」
- 第5節：3択ウォームアップ「文章題の式を立てよう！」・ミスを見破れ！「文章題の立式ミスを発見！」・導入トーク「文字が2つあると何が便利？」
- 第6節：3択ウォームアップ「文章題の式を見抜こう！」・ミスを見破れ！「整数の文章題の落とし穴！」・導入トーク「数字を入れかえると、何が起こる？」
- 第7節：3択ウォームアップ「速さ・道のり・時間を思い出そう！」・ミスを見破れ！「速さの式の間違いを探せ！」・導入トーク「速さが違う2人が走ると、どうなる？」
- 第8節：3択ウォームアップ「割合の基本を思い出そう！」・ミスを見破れ！「割合の立式ミスを発見！」・数学〇×クイズ「割合の考え方をチェック！」

文章題（第5節〜）では、問題文のマーキング・情報整理の表（`table`）・品物のイラスト（`illust`）を使い、「文章 → 表 → 式」の対応を段階的に示します。イラストは `public/illust/` の自作SVGです。

第6節では、位取り表・数字カード（`place`。十の位と一の位のカードがステップに合わせて入れかわる）と、割り算のブロック図（`bars`。わられる数＝わる数×商＋あまり）を追加しました。

第7節では、速さの図として線分図（`route`）と円周移動図（`circle`）を追加しました。答えが出るまでは模式図で表示し、答えのあとに「▶ 再生」ボタンで、求めた速さのとおりに人が動く様子（実際の速さと時間の比を保った再生）を確かめられます。再生は講師がボタンで行い、ステップを進めても自動では動きません。

第8節では、割合の帯グラフ（`ratio`。もとの量を100％とし、すべての帯を同じ目盛りで伸び縮みさせる）と、食塩水のビーカー図（`beakers`。食塩水の量・濃度・食塩の量を区別して表示し、答えのあとに混ぜる様子を再生）を追加しました。

公開URL：https://taka-t-p.github.io/math-magical-note/ （`main` にプッシュすると GitHub Actions で自動公開）

## 使い方

```sh
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 教材データを検証してから dist/ に出力
npm run preview    # ビルド結果の確認
npm run validate   # 教材データだけを検証（数式・キー参照・表示される式の検算）
```

`dist/` の中身を GitHub Pages などの静的ホスティングに置けば公開できます（サブパス配下でも動作）。

## 授業画面の操作

| キー | 動作 |
|---|---|
| → / Space / PageDown | 次のステップ |
| ← / PageUp | 前のステップ |
| Home | 問題の最初へ |
| End | 全解答を表示 |
| F | 全画面の切り替え |
| Esc | 手書きツール・講師パネルを閉じる |

ヘッダーの ‹ › で前後の項目へ移動できます（節の最初・最後では、前後の節へつながります）。

## 授業ミニコンテンツの操作

| キー | クイズ | スライド |
|---|---|---|
| → / Space / PageDown | 次の問題（正解は表示しない） | 次へ |
| ← / PageUp | 前の問題 | 前へ |
| Enter | 正解発表（ミスを見破れ！は段階的に表示） | — |
| Backspace | 発表を1つ戻す | — |
| Home | タイトル画面へ | 最初のスライドへ |

授業画面の「ミニ」ボタンから開くと、「終了」でその問題の同じステップに戻ります。

## 注意

- 教材PDF（`【2026年度】中2数学_魔法のノート_本編.pdf` / `…_指導書.pdf`）は教材データの正本です。データを追加・修正するときは必ず照合してください。
- 講師向け情報のうち `status: "draft"` のものは教材に記載のない下書きです。授業で使う前に内容を確認してください。
- 授業ミニコンテンツはすべて独自に作成した下書き（`status: "draft"`）です。`npm run validate` が表示する「講師の確認が必要」な項目を確認してから授業で使ってください。
